# hh-autoapply

Автоотклики на [hh.ru](https://hh.ru) через Playwright (браузер), без прямых API-запросов.

## Почему браузер, а не API

HH часто отдаёт **403** скриптам на axios/fetch из‑за bot detection, fingerprint, CSRF/cookies и rate limit. Реальный Chromium с сохранённой сессией ведёт себя ближе к обычному пользователю.

## Быстрый старт

```bash
cp .env.example .env
cp cover-letter.example.txt cover-letter.txt
# отредактируй HH_SEARCH_URL и текст письма в cover-letter.txt

npm run login
# войди на hh.ru в открывшемся окне, затем Enter в терминале

npm run apply
```

## Структура

```
hh-autoapply/
├── index.js           # точка входа (login | apply)
├── src/
│   ├── auth.js        # ручной логин + storageState
│   ├── apply.js       # отклики по выдаче
│   └── utils.js       # задержки, JSON-база
├── cookies/           # сессия (в .gitignore)
├── data/applied.json  # уже обработанные вакансии
└── .env
```

## Переменные (.env)

| Переменная | Описание |
|------------|----------|
| `HH_SEARCH_URL` | URL поиска с фильтрами (скопируй из браузера) |
| `MAX_APPLICATIONS` | Сколько откликов за один запуск |
| `MAX_PAGES` | Сколько страниц выдачи обойти (1 → 2 → 3… после обработки каждой) |
| `DELAY_MIN_MS` / `DELAY_MAX_MS` | Случайная пауза между откликами |
| `HEADLESS` | `true` — без окна, `false` — видно браузер |
| `SKIP_VACANCIES_WITH_TESTS` | `true` — не откликаться, если на карточке/странице есть тест |
| `COVER_LETTER_FILE` | Путь к файлу с сопроводительным письмом (рекомендуется) |
| `COVER_LETTER` | То же в одной строке `.env` (`\\n` для переносов) |

## Как не словить бан / ограничения

1. **Не гоняй объём** — 10–20 откликов за сессию, не сотни.
2. **Задержки 4–10+ секунд** между кликами, лучше разбить на несколько запусков в день.
3. **Один аккаунт = один профиль браузера** — не шарь `cookies/hh-storage.json`.
4. **Обновляй сессию** — раз в несколько дней `npm run login`.
5. **Релевантный поиск** — массовые отклики «куда попало» чаще триггерят антиспам.
6. **Не запускай 24/7** — имитируй человека: утро/вечер, перерывы.
7. При капче или странном поведении — остановись, зайди вручную, снова `login`.

## Ограничения

- Первый вход всегда **ручной** (SMS, OAuth, капча).
- Вёрстка HH меняется — селекторы `data-qa` могут потребовать правки.
- Вакансии с тестами/анкетами **пропускаются** (`requires_test`, `requires_test_hint`) — отклик идёт в отдельной вкладке, выдача не ломается.
- **Два сценария отклика на HH:**
  - **modal** — модалка, письмо + кнопка «Откликнуться»;
  - **inline** — после отклика форма внизу страницы, кнопка «Отправить» (`vacancy-response-letter-submit`).
- Письмо подставляется из `cover-letter.txt`; без файла обязательные вакансии пропускаются (`cover_letter_required`).
- Неудачные отклики **не помечаются** в базе — при следующем `apply` можно повторить.

## Команды

| Команда | Действие |
|---------|----------|
| `npm run login` | Сохранить cookies после ручного входа |
| `npm run apply` | Откликаться по `HH_SEARCH_URL` |
